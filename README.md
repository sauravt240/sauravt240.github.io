- **Structure & Logic:** Semantic HTML5, Vanilla JavaScript (ES6+), Clean Modular CSS (Custom Properties, Glassmorphism, Responsive Grid & Flexbox)
- **Motion & Dynamics:** GSAP 3, ScrollTrigger, Lenis Smooth Inertia Scrolling
- **Design Tokens:** Deep near-black palette (`#050609`), drifting blurred ambient orbs, SVG fractal noise overlay, magnetic button physics, interactive bento spotlight
- **Deployment:** Zero-build static bundle hosted directly via GitHub Pages
